## 🛠️ How to Run the Programs

1. Make sure **Java JDK** is installed:
   ```bash
   java -version
   ```
2. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
3. Go to a folder and compile:
   ```bash
   cd 04_Loops
   javac Factorial.java
   ```
4. Run the program:
   ```bash
   java Factorial
   ```
